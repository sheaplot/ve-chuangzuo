# ve创作

> 给茻人一个讲故事的空间。

ve创作是「茻新计划」的在线原型 Demo：一个面向素食者、准备开始吃素的人、以及关注动物权益者的
**故事采集与传播空间**。它不急着让人写出完整的故事，而是先用一个安静的入口、几段真实的故事、
几分钟的呼吸，陪你把故事慢慢长出来；写完之后，还可以带走一张故事卡。

**纯原生 HTML / CSS / JavaScript，无框架、无构建、无第三方依赖。**

## 功能细节

### 1. 沉浸式创作流（`index.html`）

- 六步流程：入口屏 → 此刻的心情 → 它发生在哪里 → 什么时候的事 → 想从哪里讲起 → 写作正文。
- 进入写作屏时，会根据前面选择生成一段引导语（正式版将接入真实 AI，目前是本地规则）。
- 写作时可随时点「做成故事卡」，把正文生成一张 1080×1440 的竖版图并保存到本地（canvas，无上传）。
- 保存时可选择：
  - **去保存**：写入本地草稿 `ve-draft`；已登录时同时记到个人中心；
  - **去发布**：写入 `ve-posts` 并跳转社群，**不需要登录**，方便完整走通演示流程。
- 每一步都可以「← 上一步」返回修改，已选内容会保留。
- 进入创作流后，首页下方的项目说明区会自动隐藏，保证沉浸。

### 2. 时空灵感（`inspiration.html` + `js/stories.js`）

- **固定分类白名单**：说再见 / 回家 / 群星闪耀 / 没人知道的角落 / 硬币的两面 / 一纸之令（不允许其他分类名）。
- **瀑布流布局**：CSS 多列实现，桌面 3 列、手机 2 列。
- **无限流**：首屏随机铺开 8–10 张；滚动到接近底部自动追加 6–8 张；一轮刷完后自动清空记录、重新洗牌继续。
- **同轮去重**：同一轮滑动中同一张卡片不会重复出现；换轮后才允许再次出现。
- **单篇深链**：`inspiration.html?story=martha` 会把指定故事排在第一位。
- 卡片保留「真实故事」徽标、原文外链、资料来源与「以此为灵感，开始写作」。

### 3. 故事地图（首页）

- 把 24 篇故事的真实发生地标在世界地图上（`js/story-places.js`），可拖动平移、滚轮 / 按钮缩放。
- 圆点悬停显示「标题 + 地点 + 年份」。
- 这是对早期「访客地图」的替换：访客地图会收集 IP、且空数据时只是一张空地图；故事地图只展示已公开的故事信息。

### 4. 社群（`community.html` + `js/community.js`）

- 帖子卡片包含：圆形首字头像、昵称、发布时间、情绪标签、正文、点赞、评论、关注。
- 互动全部在本地模拟：点赞可切换、关注可切换、评论即时显示。
- 在创作流里发布的故事会排在预置帖子最前面，并标注「我」。
- 预置 5 条示例帖子；页面底部注明：社群为原型演示数据，正式版将改为「投稿 → 编辑 → 发布」的先审后发流程。

### 5. 冥想（`meditation.html` + `js/meditation.js`）

- 三种模式：呼吸练习（4-4-6）、4-7-8 深呼吸、身体扫描。
- 时长可选 1 / 3 / 5 分钟，支持开始、暂停、重置。
- 结束时可写下此刻的感受并「记录」，保存在本机浏览器。

### 6. 个人中心（`profile.html`）

- 注册 / 登录（Node 服务端，密码 scrypt 加盐哈希）。
- 写作、冥想、心情三类记录；心情以「一格 = 一天」的热力图展示。

## 本地运行

```bash
npm install
node server.js          # 默认 3000，可用 PORT 环境变量覆盖
```

然后访问 <http://localhost:3000>。

> 前端的创作流、故事库、故事卡、社群互动都可以在 `file://` 下工作；
> 只有个人中心的登录与记录需要 `server.js`。

## 数据与隐私

草稿、发布与互动数据**只保存在浏览器 localStorage**，不上传任何服务器：

| 键名 | 内容 |
| --- | --- |
| `ve-draft` | 创作流保存的草稿 |
| `ve-posts` | 发布到社群的本机帖子 |
| `ve-community-interactions` | 帖子的点赞 / 关注 / 评论状态 |
| `ve-meditation-notes` | 冥想结束时的感受记录 |

账号与个人中心记录由 `server.js` 写入 `users.json` / `records.json`（仅本地文件）。
清除浏览器站点数据会一并清空本机内容。

## 故事库与内容原则

- 共 **24 篇**真实故事，分为 6 个分类。
- 编辑红线（新增故事必须遵守）：
  - **一纸之令**：只收「制度改变生活」的历史故事和社会进步成果，不收现实争议时事；罪案只收已结案、有权威来源的历史名案 / 翻案故事。
  - **硬币的两面**：收商业史和小人物与钱的故事，不收投资建议。
  - **全部栏目**：不收肉食、皮草、动物制品消费类内容。
  - 与动物相关的故事只收录保护、共生、灭绝警示类。
- 图片来源：24 张题图为 `img/covers/` 下按「年份 + 地点」生成的本地 SVG 分类题图，不依赖外链；
  正式版将替换为取得授权的实拍照片。
- 故事内容整理自公开权威资料，原文表达与观点归作者所有；ve创作只是信息集合地，不代表官方立场。

## 设计说明

- 单一强调色：鼠尾草绿 `#6f8f72`；暖白底 `#fafaf7`。
- 字体、间距、圆角等通过 CSS 变量统一管理，所有页面共享同一份 `css/style.css`（含个人中心与关于页）。
- 响应式适配手机，顶部导航在小屏下收起为汉堡菜单。
- 故事卡为 1080×1440 canvas 绘制，字体走系统衬线栈，无需联网。
