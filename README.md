# ve创作

> 给茻人一个讲故事的空间。

ve创作是「茻新计划」的在线原型 Demo：一个面向素食者、准备开始吃素的人、以及关注动物权益者的创作与交流空间。它不急着让人写出完整的故事，而是先用一个安静的入口、几段真实的灵感、几分钟的呼吸，陪你把故事慢慢长出来。

**纯原生 HTML / CSS / JavaScript，无框架、无构建、无第三方依赖。**

---

## 页面一览

| 页面 | 文件 | 说明 |
| --- | --- | --- |
| 首页 · 沉浸式创作 | `index.html` | 入口 → 情绪 → 发生地 → 时间 → 切入 → 写作，六步引导式创作流 |
| 时空灵感 | `inspiration.html` | 24 篇真实故事的瀑布流故事库，支持分类筛选与无限加载 |
| 社群 | `community.html` | 帖子流：点赞、关注、评论，本地发布的故事会出现在最前面 |
| 冥想 | `meditation.html` | 呼吸练习 / 4-7-8 深呼吸 / 身体扫描，结束后可记录感受 |

顶部导航在四个页面保持一致：**首页 / 时空灵感 / 社群 / 冥想**。

## 功能细节

### 1. 沉浸式创作流（`index.html`）

- 六步流程：入口屏 → 此刻的心情 → 它发生在哪里 → 什么时候的事 → 想从哪里讲起 → 写作正文。
- 进入写作屏时，会根据前面选择生成一段 AI 引导示例（正式版将接入真实 AI）。
- 保存时可选择：
  - **仅自己可见**：写入本地草稿 `ve-draft`，提示「已保存为草稿」；
  - **发布到社群**：写入 `ve-posts`，提示「已发布到社群 🎉」，并出现「去社群看看 →」入口。
- 每一步都可以「← 上一步」返回修改，已选内容会保留。

### 2. 时空灵感（`inspiration.html` + `js/stories.js`）

- **固定分类白名单**：说再见 / 回家 / 群星闪耀 / 没人知道的角落 / 硬币的两面 / 一纸之令（不允许其他分类名）。
- **瀑布流布局**：CSS 多列实现，桌面 3 列、手机 2 列，卡片高度随图片与文字自然变化。
- **无限流**：首屏随机铺开 8–10 张；滚动到接近底部自动追加 6–8 张；一轮刷完后自动清空记录、重新洗牌继续，**永不结束**。
- **同轮去重**：同一轮滑动中同一张卡片不会重复出现；换轮后才允许再次出现。
- 页面底部常驻一行小字「故事持续收录中…」，不打断滑动。
- 卡片保留「真实故事」徽标、原文外链、资料来源与「以此为灵感，开始写作」。

### 3. 社群（`community.html` + `js/community.js`）

- 帖子卡片包含：圆形首字头像、昵称、发布时间、情绪标签、正文、点赞、评论、关注。
- 互动全部在本地模拟：
  - 点赞可切换（数字 ±1）；
  - 关注按钮在「+关注 ↔ 已关注」之间切换；
  - 评论框输入后显示在该帖子下方。
- 在创作流里「发布到社群」的帖子会排在预置帖子最前面，并标注「我」。
- 预置 5 条示例帖子；页面底部注明：社群为原型演示数据，正式版将接入真实账号与社区审核机制。

### 4. 冥想（`meditation.html` + `js/meditation.js`）

- 三种模式：
  - **呼吸练习**：吸气 4s → 屏息 4s → 呼气 6s；
  - **4-7-8 深呼吸**：吸气 4s → 屏息 7s → 呼气 8s；
  - **身体扫描**：从脚趾到头部逐段放松。
- 时长可选 1 / 3 / 5 分钟，支持开始、暂停、重置。
- 结束时可写下此刻的感受并「记录」，保存在本机浏览器。

## 本地运行

无需安装依赖、无需构建，直接双击 `index.html` 即可预览。

推荐起一个本地静态服务器（个别浏览器对 `file://` 下的脚本有额外限制）：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

然后访问 <http://localhost:8080>。

## 数据与隐私

所有草稿、发布与互动数据**只保存在浏览器 localStorage**，不上传任何服务器：

| 键名 | 内容 |
| --- | --- |
| `ve-draft` | 创作流保存的草稿 |
| `ve-posts` | 发布到社群的帖子 |
| `ve-community-interactions` | 帖子的点赞 / 关注 / 评论状态 |
| `ve-meditation-notes` | 冥想结束时的感受记录 |

清除浏览器站点数据会一并清空这些内容。

## 故事库与内容原则

- 共 **24 篇**真实故事，分为 6 个分类：

  | 分类 | 篇数 |
  | --- | --- |
  | 说再见 | 4 |
  | 回家 | 6 |
  | 群星闪耀 | 7 |
  | 没人知道的角落 | 3 |
  | 一纸之令 | 3 |
  | 硬币的两面 | 1 |

- 编辑红线（新增故事必须遵守）：
  - **一纸之令**：只收「制度改变生活」的历史故事和社会进步成果，不收现实争议时事；其中罪案只收已结案、有权威来源的历史名案 / 翻案故事，不收血腥猎奇。
  - **硬币的两面**：收商业史和小人物与钱的故事，不收投资建议。
  - **全部栏目**：不收肉食、皮草、动物制品消费类内容。
  - 与动物相关的故事只收录保护、共生、灭绝警示类。
- 图片来源：多为 Wikimedia Commons 等公开资料；部分为 `picsum.photos` 占位图，待替换实拍图。
- 故事内容整理自公开权威资料，原文表达与观点归作者所有；ve创作只是信息集合地，不代表官方立场。

## 设计说明

- 单一强调色：鼠尾草绿 `#6f8f72`；暖白底 `#fafaf7`。
- 字体、间距、圆角等通过 CSS 变量统一管理，四个页面共享同一份 `css/style.css`。
- 响应式适配手机，顶部导航在小屏下会收紧尺寸，保证四个入口横向排得下。
